# Input Data

## traj.xyz

A 100-frame multi-frame XYZ trajectory of liquid argon generated by a
Lennard-Jones NVT Monte Carlo simulation at the liquid state point
ρ\* = 0.844, T\* = 0.85 (≈ 102 K).

### File format

Each frame consists of three sections:

```
108                          <- atom count (fixed: 108 atoms per frame)
Frame <n> box=<L>            <- comment: frame index n, cubic box side L in Å
Ar  <x>  <y>  <z>           <- 108 lines: element symbol + Cartesian coords in Å
...
```

### Parameters

| Parameter | Value |
|-----------|-------|
| Atoms | 108 Ar |
| Frames | 100 |
| Box length L | ≈ 17.1584 Å (read per-frame from comment line) |
| Reduced density ρ\* | 0.844 |
| Reduced temperature T\* | 0.85 |
| LJ sigma (Ar) | 3.405 Å |
| LJ epsilon/k_B (Ar) | 119.8 K |

### Notes

- Coordinates are in Ångströms, wrapped into [0, L).
- The box is cubic; L is the same in all three directions.
- L is printed to 6 decimal places in the comment line.
- This trajectory was generated specifically for this task and is not
  available from any public database.
